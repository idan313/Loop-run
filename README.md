# לולאה

בונה מסלול ריצה לפי מרחק, ומעביר אותו לניווט קולי ב-Apple Maps.

- מקור הנתונים: OpenStreetMap דרך Overpass. הגרף נבנה ונחקר בדפדפן (Web Worker), בלי שרת ובלי מפתח API.
- צורות מסלול: מעגלי, או מנקודה לנקודה במרחק מוגדר.
- הנקודות לאורך המסלול נבחרות לניווט כך שהדרך הקצרה ביותר בין כל שתיים היא המסלול עצמו. כך Apple Maps נצמדת אליו.
- ייצוא: Apple Maps (iOS 18.4 ומעלה), Google Maps (עד 9 נקודות), קובץ GPX.
- גובה: Open-Meteo. חיפוש כתובות: Nominatim.

## מבנה

| קובץ | תפקיד |
| --- | --- |
| `js/engine.js` | גרף, A*, בחירת נקודות ביניים לפי מרחק ברשת, נקודות ניווט |
| `js/worker.js` | הרצת המנוע מחוץ ל-thread הראשי |
| `js/data.js` | Overpass עם מראות גיבוי ומטמון, גובה, חיפוש כתובות |
| `js/export.js` | קישורי Apple ו-Google, GPX |
| `js/app.js` | ממשק ומפה (Leaflet) |
| `sw.js` | מעטפת אופליין ושמירת אריחי מפה |

## הרצה מקומית

```
python3 -m http.server 8000
```
